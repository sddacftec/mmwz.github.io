# 名门望族（简化版）

一个纯前端、免依赖的家族模拟器小游戏，主打“年度决策 + 随机事件 + 继承传代”。

## 玩法简介

- 每点击一个决策按钮，时间推进一年。
- 你需要在 **30 年内** 平衡：
  - 家族财富
  - 家族声望
  - 家族势力
  - 子嗣培养与继承
- 当家人可能因年老或健康问题离世，需要由成年子嗣继承。
- 达成较高综合分并满足门槛，可获得结局：**名门望族**。

## 运行方式

直接用浏览器打开 `index.html` 即可游玩。

## 主要系统

- 年度决策：经营商号、结交名士、培养子弟、联姻扩族、修身养息
- 随机事件：商机、灾害、名誉波动
- 传代机制：成年子嗣继承家主
- 胜负判定：30 年后综合评分 + 破产/断嗣/名誉崩塌失败条件
